# Feynman Learning Partner

> 先教你、再问你——一个真正让你搞懂知识的 AI 学习伙伴。
> AI 先用费曼精神把知识讲透，再扮演零基础新人追问，直到你真正讲清楚。

---

## 什么是 Feynman Learning Partner

这个 Skill 将费曼学习法的精髓融入 AI 对话，并做了升级。

费曼学习法的核心思想很简单：

> 如果你真的理解一个知识点，你应该能够用简单的话，把它讲给一个完全不懂的人听。

但问题来了——**如果我自己也不懂呢？**

所以这个 Skill 做了两件事：

1. **先教你**：AI 当老师，用费曼精神（大白话、比喻、从具体到抽象）把知识拆解讲透
2. **再问你**：AI 当教练，扮演零基础新人追问，检验你是不是真懂了

很多时候我们以为自己懂了：看过了、听过了、点头了、收藏了。但当真正让自己解释时，却发现说不清楚、逻辑断层、只能重复书上的话。这说明知识还没有真正内化。

这个 Skill 帮你跨越"以为自己懂了"到"真的懂了"之间的鸿沟。

## 四种模式

| 模式 | 触发方式 | 说明 |
|---|---|---|
| **默认模式（先教后问）** | "教我 JVM" / "学习 Redis 缓存穿透" | 先教学讲解，再追问验收 |
| **仅教学** | "只教不问" / "给我讲讲" | 只做讲解，不追问 |
| **仅教练** | "问我" / "考考我" / "我已经懂了" | 跳过教学，直接追问验收 |
| **完整流程** | 默认即为完整流程 | 教 → 问 → 验收 → 总结 |

## 学习流程

整个学习过程分为四个阶段：

```text
阶段一：AI 教学（费曼精神）
         ↓
阶段二：AI 追问（零基础新人视角）
         ↓
阶段三：知识验收（5~10 道题）
         ↓
阶段四：结构化总结
```

---

## 阶段一：AI 教学

AI 会像一个很会教人的老师，按以下结构讲解：

### 摸底

先问一句了解你的基础，不会盲目开讲。

### 拆解讲解

- **一句话讲清本质**：先给大白话定义
- **核心概念拆解**：是什么 → 解决了什么问题 → 怎么用
- **生活化比喻**：每个概念配一个比喻，小学生能听懂
- **对比说明**：容易混淆的概念放一起讲清楚区别
- **贯穿案例**：用完整例子从头串到尾

### 教学原则

1. 从具体到抽象，先给例子再给定义
2. 一次只讲一个概念，不堆砌
3. 用类比而不是用术语解释术语
4. 讲为什么比讲是什么更重要

---

## 阶段二：AI 追问

AI 切换为**完全不懂的零基础新人**，持续追问：

### 基础理解

- 这是什么意思？
- 为什么会这样？
- 能举个例子吗？

### 发现模糊点

- 这个词你没有解释
- 这里逻辑跳过去了
- 你用了专业术语
- 能不能换种说法？

### 深挖底层逻辑

- 本质是什么？
- 为什么需要这个东西？
- 它解决了什么问题？
- 如果没有它会怎样？

### 验证理解

- 让我复述一遍看看对不对
- 你举个反例
- 用生活中的例子解释
- 用小学生能听懂的话讲一次

---

## 阶段三：知识验收

包含 5~10 道题：

- 基础理解题
- 场景应用题
- 对比分析题
- 原理解释题
- 举例题

目标不是考试，而是验证：你是真的理解了，还是只是听过。

---

## 阶段四：结构化总结

| 模块 | 内容 |
|---|---|
| 20% 核心知识 | 最重要的关键点，大白话，不超过 10 条 |
| 一句话讲明白 | 用最简单的话总结 |
| 生活化比喻 | 帮助长期记忆 |
| 实际应用价值 | 能解决什么问题 |
| 理解漏洞 | 哪些地方讲得不够清楚 |
| 遗漏知识点 | 后续值得继续学习的内容 |

## 为什么有效

传统学习方式：

```text
输入 → 看书 / 听课 / 刷视频 → 以为自己懂了
```

费曼学习法升级版：

```text
AI 教学（讲透）
    ↓
AI 追问（暴露漏洞）
    ↓
发现不会 → 重新理解
    ↓
真正内化
```

AI 的优势：

### 不会轻易放过模糊理解

人类听众可能因为礼貌停止追问。AI 不会。

### 先教后问，两个角色互补

教学模式帮你建立框架，教练模式帮你发现漏洞。两个加起来，才是完整的费曼学习法。

### 提问有结构

从概念 → 原理 → 本质 → 验证，逐层深入。

### 最终有验收

不是简单聊天。而是真正验证掌握程度。
