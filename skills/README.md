# Personal harness layout

Skills are grouped in this repo so the Git tree stays readable. TeamAI still installs them flat into each tool (`~/.claude/skills/<name>`).

| folder | meaning |
|--------|---------|
| `yinshan/` | 银闪本职（指标、表、Java/Nacos、OSS） |
| `lark/` | 飞书 OpenAPI / 工作流 |
| `lang/` | 语言与框架规范 |
| `agent/` | Agent / Skill 工程 |
| `biz/` | 通用业务域模板 |
| `content/` | 内容、媒体、文档 |
| `search/` | 检索与外部 API |
| `personal/` | 个人向 |

Excluded: Codex `.system` builtins, unnamed `skill_<id>` dirs, TeamAI built-in skills.
